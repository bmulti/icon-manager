About this application (19 languages)

[intro] Icon Manager creates and maintains the icons and startup splash images used by your applications. It works on the shared icon library, on the applications listed in the Gateway, on the files in a folder, and on a folder of app subfolders. Icons are .ico files; splash images are PNG files with the application's name, description and version drawn on them, with an optional WEBP copy for web use. Start on Icons to see the shared library, or choose a folder in Folder or Subfolders and drop in an image. Set the shared icon folder, the Gateway file and the splash text layout in Config, then press Save Config. Click any Notes heading to open its corresponding tab. [tab:icons] The table lists every icon set found in the shared icon folder. A set is an ICO file together with its PNG sizes. Status shows Complete (an ICO and the PNG sizes 32, 48, 50, 64 and 128), Partial PNGs, ICO only, or Missing ICO (PNG files exist but there is no ICO). Updated shows the newest file in the set. Search icons filters by set name or path. Clear removes the filter. Refresh reloads the folder, and Open Folder opens it. Select a set to see a preview, its status and its files in Selected icon. Double-click a set, or press Open File, to open it. Generate from Source makes a set from an application (exe, dll, lnk) or an image (ico, png, jpg, jpeg, bmp, webp) that you choose. Generate Glyph makes a simple set from a name, one or two letters and two colours. Recipe Set generates the standard recipe icons after you confirm. Regenerate Selected rebuilds the selected set from a new source. Copy Path copies the set's path. Delete Selected removes every shared file for the selected set after you confirm; this cannot be undone. Generate from Source and Regenerate Selected replace the set if it already exists. They also save an ICO beside the application when that option is ticked in Config. If the shared icon service cannot be loaded, these buttons show a message instead. [tab:gateway-icons] This tab checks the icons of the applications in the Gateway file chosen in Config. The path of that file is shown above the table. Refresh Gateway reloads it. Icon Status shows Found when the icon can be located, Not Found when the Gateway names an icon that cannot be located, and Missing when no icon is recorded. The summary at the right counts each. Missing only hides applications whose icon is Found. Search matches the application, project, status, icon and path. Narrow layout puts the preview below the table instead of beside it. Generate Selected from App makes an icon for the selected application. Generate All Missing does this for every application that is not Found, after you confirm; applications without a usable source get a simple letter icon. Choose PNG, JPG or ICO, or dropping one file on the target at the bottom, assigns that image to the selected application. Icon crop chooses whether a wide image is cropped from the Center or the Right side. Each of these writes the ICO beside the application, writes its _spash.png, and records the icon in the Gateway file. If the files already exist you are asked before they are replaced, and if the Gateway file cannot be saved they are put back as they were. If the Gateway file was changed elsewhere it is reloaded and you must repeat the action. Web links, and applications whose file cannot be found, cannot be given an icon here. [tab:folder] Choose a folder with Browse Folder. The table lists the files directly inside it, not subfolders. For Python files, Named, Description and Version are read from the project, named, version and description lines near the top of the file; nothing is run. The .ico and _splash.png columns show Yes or No for Python files only. Select a file to see its details and its current splash picture. If it has no splash yet, the preview shows how one would look on a sample background. Drop a PNG or JPG on the target at the bottom, or press Choose PNG or JPG, to create three files beside the selected Python file: <name>.ico, <name>_splash.png and <name>_splash.webp. Existing files with those names are replaced. The splash text comes from the template in Config. Drop exactly one image at a time; links and web downloads are refused. Make all PNG into WEBP copies every PNG in the folder and all folders beneath it to a WEBP of the same name, replacing any that exist. It runs in the background and the status line shows progress. Icon crop works as on Gateway Icons. Right-click a file for Explore, Open folder in Explorer, Make a Copy, Paste File to Folder, Copy File Path, Copy image to clipboard (Windows only) and Delete (asks first). A copy is named "- Copy", and pasting never replaces an existing file. [tab:subfolders] Use this tab when each application lives in its own subfolder, as <folder>\<folder>.py. Choose the parent with Browse Root and press Populate. The table lists every subfolder with whether its .py, .ico and _splash.png exist, and the summary counts how many are missing an .ico or splash. Missing only hides folders that already have both. Select a folder, then drop a PNG or JPG on the target, or press Choose PNG or JPG, to write <folder>.ico, <folder>_splash.png and <folder>_splash.webp in that subfolder, replacing existing files. The folder's name is used as the file name on the splash. When Missing only is ticked, the selection moves on to the next folder that still needs files. Make all PNG into WEBP and Icon crop work as on the Folder tab. Right-click a row to explore the folder or any of its files. [tab:process] This page shows how icons are found and made, and the health of the shared icon folder. The four counts show the icon sets, the complete sets, the sets missing an ICO, and the partial sets. The flow runs from a request, to reusing an existing icon, to converting a matching image, to extracting an icon from an exe, dll or lnk, and finally to a simple letter icon. Each step is tried only if the one before found nothing. New sets contain ICO sizes 16, 24, 32, 48, 64, 128 and 256, and PNG sizes 32, 48, 50, 64 and 128. Other applications can ask for an icon with request_icon. Nothing on this page is edited. [tab:config] Set the shared icon folder and the Gateway file. The icon folder is created if it does not exist. Tick the option to also save an ICO beside the requesting application when generating from a source. Press Save Config; the status line confirms it. Your choices are kept in cpc_icon_manager.json and restored the next time Icon Manager opens. Edit JSON saves and then opens that file. The page scrolls in a smaller window. Splash Overlay Template controls the text drawn on every splash image. Final splash height is the height in pixels of the finished image (400 by default). The text box holds one line per row of text; use the listed fields such as {{window_title}}, {{purpose_note}}, {{file_name}}, {{version}}, {{source_date}}, {{version_or_source}}, {{app_name}}, {{project}} and {{desc}}, and they are filled from each application. A blank line leaves a gap. Each line has its own style row: font, size, text colour, and optional background and shadow with their colours. Colours are written as #RRGGBB, or chosen with the ... button. Rows follow the lines of text, and a line style changes when you leave the text box. [tab:splash] This tab turns the original _spash.png of each Gateway application into a finished _splash.png with the template text added. The original is never changed. The table shows, for each application, its window title, version or source date, purpose note, and whether the original and the finished file exist. Search filters the list; Refresh Gateway reloads it. Select an application to see its Gateway record and a preview. Select several to create them together. Preview Selected redraws the preview using the current template. Create Selected writes the _splash.png beside each selected application, replacing any earlier one. Sample shows the template on example values and a sample background. An application whose original _spash.png or application file is missing cannot be previewed or created. When Icon Manager starts on its own, it shows the application's own _splash.png, or the _spash.png if there is no finished one, while it loads. [tab:ui-choices] Choose a colour theme, spacing and window size. These settings control how the app looks. Icon folders, the Gateway file and splash text belong in Config. When Icon Manager is attached to another application, that application controls the window and its appearance, and this tab may be hidden. [tab:gateway] Use the shared launcher to find and open registered applications, files, folders and links. Gateway is separate from the icon work on the other tabs, and it appears only when Icon Manager shows it. If the launcher cannot be loaded, you can open the Gateway file from this tab.
